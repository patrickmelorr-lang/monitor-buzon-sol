# Imágenes del sitio público

Las imágenes que se publican van **en esta carpeta**.

## Antes de agregar una captura

Este repositorio es **público**. Una captura del Buzón SOL muestra razón social, RUC y
asuntos de notificaciones reales. Antes de subirla:

1. **Tapa con un rectángulo opaco** (no con desenfoque, que a veces se puede revertir):
   razón social, RUC, números de documento y el nombre de usuario de la barra superior.
2. Revisa también la **barra de direcciones** del navegador y las pestañas abiertas.
3. Si la imagen no se puede censurar bien, guárdala con el sufijo `-PRIVADO.png`:
   el `.gitignore` la bloquea automáticamente.

El guardián de commits no puede leer lo que hay dentro de una imagen: **esa revisión es manual.**
